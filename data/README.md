# Data directory

`seeds.json` contains the small official-source seed registry used by the crawler. It is intentionally small so discovery can find further pages within each official domain rather than hard-coding every scholarship as a source record.

`sample_scholarships.json` is a dated reproducibility snapshot checked on 2026-10-02. It includes official-source evidence and both active and expired examples. The live crawler should be used to refresh dates and status before real use.
